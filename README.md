# Sharon Ekula — Portfolio

Personal portfolio site built with Next.js, TypeScript, Tailwind CSS v4, and Motion.

🔗 [sharonekula.vercel.app](https://sharonekula.vercel.app)

## Stack

- Next.js 16
- TypeScript
- Tailwind CSS v4
- Motion (Framer Motion)

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.
